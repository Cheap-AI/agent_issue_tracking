"An AI-native Issue Intelligence Platform where each Issue is a living, evolving collection of knowledge maintained collaboratively by AI agents."

# Project Vision

I am building an AI-native Issue Intelligence Platform.

The goal is NOT to build another news reader, chatbot, or search engine.

The purpose of this platform is to continuously discover, organize, evaluate, and maintain the world's most important ongoing issues so that people can quickly understand what is happening without reading hundreds of articles every day.

The platform should answer questions like:

* What are the most important things happening today?
* Why are they important?
* What changed recently?
* What evidence supports the current understanding?
* What is still uncertain?
* How has this issue evolved over time?

Every issue should become a living knowledge space that evolves continuously as new information arrives.

---

# Core Philosophy

The product is NOT documents.

The product is NOT AI agents.

The product is understanding.

Documents exist only to support understanding.

Agents exist only to maintain knowledge.

Users come to understand Issues.

---

# What is an Issue?

An Issue represents an ongoing real-world topic that evolves over time.

Examples:

* NVIDIA's AI strategy
* AI replacing software engineers
* US-China semiconductor competition
* Federal Reserve interest rate policy

An Issue is a container for all knowledge related to that topic.

Each Issue should continuously evolve as the world changes.

---

# Platform Architecture

The platform contains two kinds of knowledge.

## 1. Global Knowledge

Global knowledge is shared across every issue.

Examples:

* Issue ranking framework
* Evaluation rubric
* Editorial policies
* Prompt templates
* Classification taxonomy

These assets define HOW the platform thinks.

They are global and version controlled.

---

## 2. Issue Knowledge

Each Issue contains its own evolving knowledge.

Possible components include:

* Timeline
* Research
* Sources
* Summary
* Open Questions
* Predictions (future)
* Related Issues (future)

Each component is versioned independently.

---

# Agents

Agents do not exist to chat with users.

Agents exist to improve the platform's understanding.

Possible responsibilities include:

* Discover new issues
* Detect meaningful updates
* Read new information
* Update research
* Extend timelines
* Improve summaries
* Add supporting sources
* Suggest importance score changes

Agents collaborate through shared knowledge rather than direct communication.

---

# Ranking

Ranking is global.

The platform maintains one ranking framework that determines how issues should be prioritized.

Agents use this framework to evaluate issues.

The framework itself can evolve through version-controlled updates.

---

# MVP

The first milestone is intentionally simple.

Build a system where:

1. An Issue exists.
2. An Issue contains one Knowledge Asset (Research).
3. An agent reads the current version.
4. The agent updates the document.
5. A new version is stored.
6. Previous versions remain immutable.

The objective is to validate the architecture before adding additional agents or knowledge types.

---

# Long-term Goal

Eventually the platform should function like an autonomous research organization.

Instead of publishing articles, it continuously maintains living issues.

Instead of producing one-time reports, it continuously improves understanding.

The value of the platform comes from helping people understand the world's most important evolving issues at a glance.
